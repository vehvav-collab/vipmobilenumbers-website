How to Request a Specific Mobile Number Pattern

A simple checklist for customers who want a particular ending, repetition, sequence or operator preference.

Updated for the current website structure. Availability, pricing and operator conditions should always be confirmed directly before a transaction.

1. Write the pattern

Describe the pattern in plain language and, if possible, provide an example structure.

2. List must-have digits

Separate must-have digits from nice-to-have digits. This gives the enquiry a clear priority order.

3. State operator preference

If you specifically want Jio, Airtel, Vi or BSNL, say so. If operator is flexible, say that too.

4. Share your budget if relevant

A budget can help narrow the options. It is optional unless the seller requests it.

5. Confirm before proceeding

Verify the exact number, current price, operator, activation process and any applicable terms before completing a transaction.
